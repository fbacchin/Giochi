## Pubblicazione

Il sito è servito da GitHub Pages dal ramo `gh-pages`. Non serve toccarlo: a ogni push
su `main` il lavoro [`Pubblica il sito`](.github/workflows/pubblica.yml) allinea `gh-pages`
da solo. Si spinge su `main` e basta.
